## Priority Issues

**[P1] Dark-theme hover fails on pinned cream surfaces.** `hover:text-rose-warm` (page.tsx:54) / `group-hover:text-gold-bright` (SubjectTeachers.tsx:126) on `--brand-paper` cards; dark token inverts to light rose/gold → ≈1.9:1 and ≈1.7:1, invisible at the intent moment. Detector's 1.3:1 muted-on-paper is the same family: pinned paper stays light while dark muted-foreground inverts. Fix: theme-invariant hovers on pinned surfaces (color-mix against paper-foreground), pinned dark-muted variant. Suggested: `$impeccable colorize` follow-up / `$impeccable polish`.

**[P1] Three section-heading voices + h2 before h1.** Find-your-grade 36px Boogaloo bold (HomeGradeNav.tsx:19), What's New / Find-a-lesson-in-seconds 26px extrabold (page.tsx:104,150), subject board title 22px Caveat pill (SubjectTeachers.tsx:77) — all faux-bold (only Boogaloo 400 loaded). A11y order has h2 before h1. Fix: Lilita One 26px section role for all four; board title real h2; h1 above grade region in source. Suggested: `$impeccable typeset`.

**[P1] Closing Tip sells grade-aware subject buttons this page doesn't show.** "Daycare keeps only the subjects that fit" — home cards route to fixed queries, no grade filtering. Silent trust spend. Fix: link proving it (→ /grade/daycare) or move sentence to grade pages. Suggested: `$impeccable clarify`.

**[P2] Hero artifacts float without support layer.** DESIGN.md says leather is homepage base; taped card + pinned Polaroid sit on bare cream with CSS-shape fasteners (clip-path tape, radial pins) instead of governed `fastener-*` assets. Fix: navy/leather hero support band; swap to fastener asset classes. Suggested: `$impeccable layout` / `$impeccable bolder`.

**[P2] Bottom-half search duplication.** MobileQuickSearch + CurriculumPlanner search + header search + chips = same action 4 ways; final band repeats search instead of print-and-go story. Fix: delete duplicated search column, end on grade CTA. Suggested: `$impeccable layout` / `$impeccable distill`.
