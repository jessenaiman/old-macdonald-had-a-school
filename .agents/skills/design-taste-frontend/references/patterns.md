# Optional design patterns

Load only for a brief that explicitly needs distinctive marketing composition or advanced motion. Prefer `/branding` and `old-macdonald-asset-system` for local visual decisions.

- Use an asymmetric split, editorial manifesto, or real media hero when the brief supports it; do not force a centered hero or bento grid.
- Use cards only when elevation communicates hierarchy. Otherwise use spacing, grouping, or sparse dividers.
- Use one accent palette, radius scale, and page theme. Test contrast in every supported mode.
- Use Motion for local state/reveal transitions. Use GSAP only for real pinning or scroll choreography, with cleanup and reduced-motion fallbacks.
- Never use `window.addEventListener('scroll')` for visual progress. Prefer Motion, IntersectionObserver, CSS scroll-driven animation, or ScrollTrigger.
- Do not use fake product screenshots, invented metrics, decorative metadata, or visual labels without user meaning.
- For forms, keep labels visible, errors adjacent, focus visible, and controls readable.
