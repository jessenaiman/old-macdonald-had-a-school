# Source-review mode

Use for lyrics, song history, source comparison, actions, chords, and version review. Inspect the original PDF/page or web source before trusting Markdown.

- Preserve source order and real LF stanza breaks.
- Keep materially different versions separate; title matches are not enough.
- Store continuation prompts, verse substitutions, and repeat instructions as song actions, not lyric lines.
- Store actions at line, section, or song scope only when the source supports that precision.
- Store chords only at documented line, section, or song precision and label provenance.
- Mark extracted material pending review; do not turn OCR or an unverified transcription into a source fact.
- For historical claims, use the local knowledge index/retrieval guide and cite creator, year, and local source path.
