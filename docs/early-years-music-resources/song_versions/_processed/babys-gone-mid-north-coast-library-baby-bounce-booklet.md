# Baby's Gone!

Baby's gone, where is she?
Peek-a-boo! Now I see.
Gone again, where'd she go?
Peek-a-boo! I found her toe!

**Printed actions:**

- Line 1: Cover eyes with hands.
- Line 2: Take hands away and 'find' baby.
- Line 3: Cover eyes again.
- Line 4: Tickle toes.
