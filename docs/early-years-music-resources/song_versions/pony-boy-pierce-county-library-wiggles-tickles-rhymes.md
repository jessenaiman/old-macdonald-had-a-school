# Pony Boy

Pony boy, pony boy
Won’t you be my pony boy?
Here we go,
Don’t go slow,
Giddy-up, giddy-up, giddy-up
Whoa!

**Printed variant instruction:** Repeat with pony girl.

**Source review:** Verified against PDF page 15 / printed page 14. The source
does not print a movement action for this song. Actions printed for neighboring
songs must not be attached to Pony Boy.
