## Cast, teaching roles, and visual ownership

This file is the portable canonical roster. It contains the names, semantic keys, portrait paths, colour references, roles, and safe activity contexts needed to understand the cast without opening the website or searching `public/`. The rendered page uses the same production character components to show those facts in context.

Each identity pairs one unchanged [canonical portrait](#assets) with one signature colour from `globals.css`. Change a character colour only in `globals.css`; do not pass a colour, portrait, texture, or ink value into a component. Curriculum artwork remains independent: choose and include it through the [semantic icon catalogue](#icons).

### Where each character asset family lives

| Asset family | Folder | Intended use |
| --- | --- | --- |
| Full-body canonical portraits | `public/staff_and_students/` | Full-size character cards, introductions, and scenes. Do not shrink these into compact rows. |
| Embroidered character badges | `public/patches/` | A substantial attached badge on a card or board, positioned at the top-right when used as an attachment. These multi-megabyte sources are not tiny menu icons. Old MacDonald currently has no separate exported badge in this folder. |
| Compact face patches | `public/icons/early-years/face-patches/` | Compact identity beside a character name or in a menu. |
| Compact face busts | `public/icons/early-years/face-busts/` | Alternate compact identity beside a name when the bust treatment is needed. |
| Blank identity patches | `public/design-assets/blank-felt-patches-v1/individual-patches/` | Character-colour felt foundations in circle, square, and rectangle shapes. |
| Repeatable identity felt | `public/design-assets/web-material-library-v1/felt/` | Character-owned fabric surfaces; select through the semantic `cast-*` identity. |

The compact pair beside each name below is connected through `app/brand-assets.css` using `data-character`; the MDX does not carry runtime asset URLs. Inventory warnings for individual early-years extractions remain relevant when choosing one for production.
