# Cast and learning roles

Every page in this system starts with **who** is teaching or learning, **why** they belong in the lesson, and **what** the page must communicate. The cast defines 16 canonical identities — 8 staff and 8 students — each with a specific educational responsibility, learning behavior, and permitted actions.

> **Principle:** Choose by educational responsibility, learning behavior, and permitted action — not decoration.

## Teach the system

**Identity → role → allowed action → governed asset.**

| Use | Avoid |
|-----|-------|
| Unchanged portraits | Recolouring artwork |
| Exact semantic identity | Invented roles |
| Documented facts | Decorative icons |
| Purposeful materials | Generic felt substitutes |

## Quick reference

Each character has a semantic colour token (`cast-old-macdonald`, `cast-hopper`, etc.) that must be used for any coloured element representing that character. Never invent a colour or repurpose another character's token.

Each character has governed artwork forms:
- **Face** — transparent 2D face
- **Backed** — 2D face with backing
- **Full** — transparent full character portrait
- **Felt** — large felt embroidered patch (badge)

These are referenced via the `brand-asset` utility classes, never by raw asset URLs.
