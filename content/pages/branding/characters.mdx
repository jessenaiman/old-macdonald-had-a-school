# Cast & Teaching Roles — Single Source of Truth

Grades, Subjects and Characters all have a color value. These values are used to style individual locations that match.

This Markdown file is the source of truth for cast identity, approved colors, roles, personalities, artwork meaning, and permitted actions.

`app/globals.css` is the implementation layer for those approved colors. It may expose them as CSS variables and shadcn theme tokens, but it must not invent, derive, remap, or optimize them.

The root layout applies the theme. Components consume the theme. No TypeScript file, registry, database, or component may define cast identity or design meaning.

## Old MacDonald had a School - Characters
