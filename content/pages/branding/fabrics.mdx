<h3 className="mt-8 font-heading text-xl font-normal leading-none text-balance">Selection rules</h3>

- Character or portrait object: use its matching `cast-* material-felt` combination.
- Grade patch: use the documented `data-grade` mapping; do not choose a cast class manually.
- Neutral attached textile: use `material-woven-fabric` only when the object visibly behaves like cloth.
- Readable information: use paper, not fabric.
- Working wall: use cork only for the board holding attached pieces.
- Generic page chrome or shared control: use semantic color tokens and shadcn variants, with no cast texture.

<h3 className="mt-8 font-heading text-xl font-normal leading-none text-balance">Production boundary</h3>

The library contains 76 individual repeat tiles across six families. Availability is not automatic approval. A production component may request only a semantic class or variable already registered in `brand-assets.css`. Unregistered identity varieties remain source assets until a real component need establishes their semantic owner and usage.

- Do not paste an asset URL into MDX, TSX, a CSS module, or a shadcn `className`.
- Do not use contact sheets or the leather staff-colors composite as surfaces.
- Do not register every file pre-emptively; add the smallest semantic mapping required by an approved component.
- Do not use fabric to carry paragraphs, instructions, form labels, or dense teacher information.
- Paper remains the default readable Card surface. Fabric appears as an attached specimen, identity patch, or owned object inside that paper structure.
- A registered inventory sample is not a control variant. The reference names a production consumer only when the actual site uses one.
