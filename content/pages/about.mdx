## Why I built this
Kicker: The problem
Teachers should not have to open twenty tabs to understand how to begin one lesson. Many resource sites increase choice without reducing planning time. This project starts with the curriculum topic and organizes only the information that helps a teacher act.

## How I work
Kicker: The approach
I look for the smallest useful structure, verify the educational source, and design the interface around the decision someone needs to make next.
- Curriculum and standards mapping
- Resource verification and editorial curation
- Spreadsheet-to-content workflows
- Visual systems for educational projects

## What this project demonstrates
Kicker: The work
This website is both a teacher resource and an example of my approach to educational product design: make the source material editable, keep the interface calm, and remove features that do not improve the user’s next decision.

## Current direction
Kicker: Building in public
The first release focuses on separate Grade 1 and Grade 2 resources. The content remains intentionally editable so each lesson structure can improve through teacher review before hundreds of topics are added.
