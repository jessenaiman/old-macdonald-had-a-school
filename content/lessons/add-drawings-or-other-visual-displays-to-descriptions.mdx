## Lesson goal

Students add a drawing, labels, arrows, or a simple sequence to make a description clearer.

## Prepare

- Show two descriptions of the same familiar object: one with a useful labelled drawing and one with decoration only.
- Provide paper divided into **words** and **visual**.
- Gather pencils, crayons, labels, and optional picture symbols.

## Teaching sequence

1. Read both examples. Ask which visual helps the reader learn something new and why.
2. Model adding one label or arrow that explains a detail, not merely colouring.
3. Students choose a previous oral description or class object and add a visual that clarifies it.
4. Partners use the visual to say one new thing they learned.
5. Invite revision: add, remove, or relabel one part so the visual communicates more clearly.

## Access and observation

- Offer stamps, photos, cut-outs, assistive drawing tools, or digital annotation.
- Students may dictate their description or explain the visual orally.
- Notice whether the visual adds or clarifies information for an audience.
