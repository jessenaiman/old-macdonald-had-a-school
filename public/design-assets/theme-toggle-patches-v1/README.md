# Theme toggle patch family

Transparent-ready felt appliqués for the compact header prototype.

- `sun-moon-patches.png` — two-up transparent asset sheet; sun on the left, moon on the right, generous separation.
- `sun-patch.png` — individual light-mode sun patch.
- `moon-patch.png` — individual dark-mode moon patch.

The patches use the project’s locked navy, gold, cream, and tan-thread vocabulary. The source images were generated on a flat chroma key and locally keyed to alpha; the green source files were removed after validation. They are intended to be placed on the official navy header and scaled down as a paired theme control.
